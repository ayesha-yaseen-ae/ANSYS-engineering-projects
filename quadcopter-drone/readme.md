# Quadcopter Aerodynamic Analysis

## Overview

Computational Fluid Dynamics (CFD) analysis of a quadcopter configuration using **ANSYS Fluent** to investigate the airflow around the drone body.

The analysis was performed by creating a surrounding fluid domain around the quadcopter and defining appropriate flow boundaries to study the aerodynamic behavior of the configuration.

## Software Used

* ANSYS Workbench
* ANSYS Fluent
* CFD post-processing tools

## Analysis Setup

The computational domain was defined as a fluid enclosure surrounding the quadcopter geometry.

### Boundary Conditions

* **Drone body:** Wall
* **Velocity inlet:** Velocity-inlet
* **Outlet:** Pressure-outlet
* **Enclosure walls:** Wall

The report contains the generated mesh and CFD setup information, along with the resulting analysis figures.

## Mesh

The final CFD mesh contained approximately:

* **257,308 nodes**
* **1,418,405 elements**

The analysis includes visualizations of the computational domain and aerodynamic flow around the quadcopter.
